# Nardora Branding

This directory is the source location for Nardora player-facing brand assets.

## Approved brand direction

- Product name: **Nardora**
- Repository name: `Long-Narde` (kept to preserve existing links)
- Store title working version: **Nardora: Long Narde Game**
- Game-category wording may use: **Long Narde**, **Long Narde & Backgammon**, and **Uzun Narde / Uzun Tavla Oyunu**

## Visual direction

- Dark walnut wood
- Gold accents
- Warm cream typography
- Restrained red accent
- App icon concept: a distinctive gold **N**, supported by subtle dice/checker details

## Planned assets

- `logo/` — primary and compact logo variants
- `icons/` — app, PWA, Android, iOS and store icons
- `splash/` — launch/splash artwork
- `store/` — screenshots, feature graphics and promotional artwork

Do not commit unlicensed third-party assets. Record asset origin and license status in `ASSET_PROVENANCE.md`.
