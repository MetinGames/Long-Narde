# Roadmap

This roadmap separates verified completed work from future planning. Items in later sections are not promises or launch commitments.

## Completed

- Local long narde gameplay with a bot opponent.
- Start screen that pauses gameplay until the user begins a match.
- Shared Turkish, English, and Russian i18n flow.
- Start-screen and side-panel language selectors kept in sync.
- Local player statistics with a modal summary.
- How-to-play guide modal.
- Turn timer and timeout controller.
- Undo and turn-confirm controls.
- Responsive desktop and mobile layout handling.
- Anadolu and walnut theme support.
- Keyboard-accessible dialogs and visible status updates.

## Short term

- Git branch envanteri ve güvenli stale branch temizliği.
- `app.js` dosyasının küçük, testli adımlarla modülerleştirilmesi.
- UI ve core klasör sorumluluklarının gözden geçirilmesi.
- Event listener yaşam döngüsü denetimi.
- iOS `dvh`, safe-area ve ekran döndürme incelemesi.
- Oyuncu geri bildirim sistemi ve GitHub issue formları.
- Nardora marka geçiş planı.

## Medium term

- Kullanıcının özgün gerçek zar ve pul kayıtlarının entegrasyonu.
- Hard bot için Long Narde kurallarına uygun çok hamleli planlama.
- Android ve iOS paketleme/yayınlama hazırlığı.
- Profil, avatar ve daha gelişmiş yerel istatistikler.

## Long term

- Gerçek çevrimiçi iki oyunculu özel masalar.
- Arkadaş daveti.
- Yazılı sohbet ve hızlı emojiler.
- İsteğe bağlı sesli/görüntülü görüşme.
- Kamera ve mikrofonun varsayılan kapalı olması.
- Sıralama, puan, ülke/klan sistemi.
- Profil paylaşımı için gizlilik ve moderasyon sistemi.

## Requires research

- Hamle hesaplama benchmark’ı.
- Gerekirse memoization.
- JSON tabanlı state kopyalama maliyetinin ölçülmesi.
- Bot hesaplamaları için Web Worker ihtiyacının ölçülmesi.
- Ses ve görsel preload davranışının ölçülmesi.
